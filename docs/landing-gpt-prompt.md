# 지피티 프롬프트 — 랜딩페이지 디자인 시안 (이미지)

지피티에서 **그림으로** 시안을 받아 오시고,
그 그림을 보고 제가 쪽을 만듭니다.

---

> ## ⚠️ 먼저 알아 두실 것
>
> **이미지로 만들면 한글 글자가 깨집니다.**
> 지피티의 그림 기능은 한글을 제대로 쓰지 못합니다.
> 「변호사선임비용」이 「변호샤선잉비욯」처럼 나옵니다.
> **이건 못 고칩니다. 모델의 한계입니다.**
>
> 그래서 이렇게 나눕니다.
>
> | 그림에서 가져올 것 | 제가 넣을 것 |
> |---|---|
> | 짜임새 · 여백 · 비율 | **글자 전부** |
> | 색과 분위기 | 조문 · 숫자 |
> | 어디에 무엇을 둘지 | 버튼 · 링크 |
>
> **그림의 글자는 보지 마십시오.** 「여기쯤에 제목,
> 그 아래 표」만 보시면 됩니다.
>
> ### 한 장에 다 담지 마십시오
>
> 랜딩페이지는 세로로 깁니다. 한 장에 다 넣으면 뭉개집니다.
> **아래 프롬프트를 세 번 나눠** 넣으십시오.
> 어느 부분인지만 바꾸면 됩니다.

# 1단계 — 공통으로 먼저 넣으실 것

```
한국 법무법인의 랜딩페이지 웹 디자인 시안을 만들어 주세요.
실제 웹사이트 화면을 위에서 아래로 캡처한 것처럼 보이게,
UI 목업 형태로 그려 주세요.

## 분위기
- 차분하고 절제된 고급스러움. 대형 로펌의 품격.
- 여백이 아주 넉넉합니다. 글자와 글자 사이가 답답하지 않습니다.
- 화려하지 않습니다. 느낌표, 빨간 경고색, 큼지막한 할인 배너,
  카운트다운 같은 것은 절대 넣지 마세요.
- 사진은 거의 쓰지 않습니다. 글자와 선과 여백으로 만듭니다.

## 색 (이 값만 쓰세요)
- 바탕 #fcfcfb (노란기 없는 오프화이트)
- 구간 교대 바탕 #f1f1ef
- 글자 #17171a, 흐린 글자 #8a8a90
- 선 #e2e2e0 (아주 얇게)
- 강조 금색 #8a7248 (아주 좁은 자리에만)
- 어두운 구간 바탕 #141416, 그 위 글자 #e4d5b7
- 노란색 #fee500 은 카카오톡 버튼 하나에만

색을 아껴 씁니다. 넓은 면을 색으로 칠하는 곳은
카카오톡 버튼뿐입니다.

## 글꼴 느낌
- 큰 제목은 가는 한글 명조(세리프). 아주 크고 가늘게.
- 본문은 한글 고딕, 가늘게, 줄 간격 넓게.
- 영문 소제목은 아주 작은 대문자에 자간을 넓게.

## 화면
가로 1440px 데스크톱 화면으로 그려 주세요.

## 글자에 대하여
한글 글자가 정확하지 않아도 괜찮습니다.
저는 짜임새와 분위기만 볼 것입니다.
글자 자리는 선이나 흐린 글자 덩어리로 표현해도 됩니다.
```

# 2단계 — 여기에 이어서 넣으실 것 (한 번에 하나씩)

## ① 머리말 화면

```
이번에는 맨 위 머리말 화면만 그려 주세요.

- 바탕은 어두운 #141416.
- 위에 얇은 머리띠. 왼쪽에 법인 로고 자리, 오른쪽에 메뉴 몇 개와
  전화번호.
- 가운데 왼쪽 정렬로 아주 큰 한글 명조 제목 두 줄.
- 그 아래 본문 두세 줄.
- 그 아래 버튼 세 개가 가로로.
  첫째는 밝은 크림색 채운 버튼,
  둘째는 노란색(#fee500) 채운 버튼,
  셋째는 테두리만 있는 버튼.
- 맨 아래에 아주 작은 글씨로 실적 한 줄과 담당 변호사 소개 한 줄.
- 오른쪽 절반은 비워 두거나 아주 어둡고 은은한 사진.
```

## ② 본문 화면

```
이번에는 본문 구간을 그려 주세요. 네 개의 구간이 위아래로
이어지는 모습입니다.

구간 1 — 흰 바탕(#fcfcfb)
  왼쪽에 아주 작은 영문 대문자 소제목, 그 아래 큰 한글 명조 제목.
  오른쪽에 설명 한 문단. 제목과 설명이 좌우로 나뉜 구성.

구간 2 — 회색 바탕(#f1f1ef)
  큰 제목 아래에 표가 하나. 표는 세로줄이 없고 가로선만 아주 얇게.
  머리줄만 살짝 진한 바탕. 두 칸짜리 표.

구간 3 — 흰 바탕
  왼쪽에 금색 세로선(2px)이 있는 인용 상자. 상자 안은 아주 연한
  미색 바탕(#f6f4ef). 위에 작은 글씨로 출처 이름, 아래 본문 두 줄.
  법조문을 인용한 칸입니다.

구간 4 — 어두운 바탕(#141416)
  가운데에 크림색(#e4d5b7) 한 문장만. 위쪽과 왼쪽에만 아주 가는
  금색 선. 다른 장식은 없음.

각 구간 사이의 위아래 여백을 아주 넉넉히 주세요.
```

## ③ 상담 화면과 휴대폰 화면

```
이번에는 두 가지를 그려 주세요.

왼쪽 — 맨 아래 상담 구간
  어두운 바탕(#141416). 가운데 정렬.
  큰 한글 명조 제목 한 줄, 본문 두 줄,
  그 아래 버튼 세 개가 가로로.
  맨 아래 아주 작은 글씨로 주소와 전화번호.

오른쪽 — 같은 쪽의 휴대폰 화면 (가로 390px)
  머리말이 위에서부터 보이고,
  화면 맨 아래에 늘 붙어 있는 가로 막대가 있습니다.
  그 막대는 두 칸으로 나뉘고 왼쪽은 전화, 오른쪽은
  노란색 카카오톡입니다.
  버튼 높이는 손가락으로 누르기 좋게 넉넉합니다.
```

# 영문 프롬프트 (그림이 마음에 안 들 때)

그림 모델은 영어를 더 잘 알아듣습니다.
위 한글 프롬프트로 나온 그림이 어수선하면 이것을 써 보십시오.

```
A high-end Korean law firm landing page UI mockup, desktop 1440px,
viewed as a flat screenshot.

Mood: restrained, editorial, quiet luxury. Generous white space.
Absolutely no exclamation marks, no red alert colors, no sale
banners, no countdown timers. Almost no photography — built from
type, hairlines and space.

Palette, use only these:
background #fcfcfb, alternate band #f1f1ef, text #17171a,
muted text #8a8a90, hairlines #e2e2e0, gold accent #8a7248 used
only in tiny areas, dark band #141416 with #e4d5b7 text on it,
and #fee500 for exactly one button.

Type: very large, very light Korean serif headlines. Light Korean
sans body text with wide line height. Tiny wide-tracked uppercase
Latin eyebrows above headlines.

Korean glyphs do not need to be legible — I only need the layout,
proportions and mood.
```

# 그림을 받으신 뒤에

**그림 파일을 저에게 보내 주십시오.** 그러면 제가

1. 그림을 보고 짜임새를 읽고
2. `docs/랜딩-본문만.md` 의 **진짜 글자**를 넣고
3. 법인 홈페이지의 색 · 글꼴 · 버튼을 그대로 써서
4. 휴대폰에서 넘치는 곳을 잡고
5. `traffic-insurance.html` 로 만들어 올리겠습니다.

**그림의 글자는 무시하겠습니다.** 깨져 있어도 괜찮습니다.

# 다른 방법 — HTML 로 받기

그림 대신 **HTML 코드로** 받으시는 방법도 있습니다.
그러면 한글이 깨지지 않습니다. 다만 디자인은 그림만 못합니다.

지피티에 이렇게 말씀하시면 됩니다.

```
위 디자인을 HTML 한 파일로 만들어 주세요.
CSS는 <style> 안에 넣고, 아래 본문을 그대로 쓰세요.
숫자와 조문은 한 글자도 고치지 마세요.
```

그다음 `docs/랜딩-본문만.md` 를 붙여 보내시면 됩니다.

**둘 다 해 보시고 마음에 드는 쪽을 주셔도 됩니다.**
