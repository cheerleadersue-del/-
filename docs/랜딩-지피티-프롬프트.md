당신은 대한민국 법무법인의 랜딩페이지를 만드는 웹 디자이너이자
프런트엔드 개발자입니다. 아래 조건을 지켜 HTML 한 파일로
완성해 주세요. CSS는 <style> 안에, 자바스크립트는 꼭 필요한
만큼만 <script> 안에 넣어 한 파일로 주세요.

## 1. 이 쪽의 목적

유일한 목적은 **전화 상담 신청**입니다.
읽히는 쪽이 아니라 **전화가 걸리는 쪽**으로 만들어 주세요.

읽는 사람은 **교통사고로 사람을 다치게 해 입건된 가해자**입니다.
지금 불안하고, 전과가 남을까 걱정하고,
**변호사비가 얼마나 들지 몰라서 전화를 못 걸고 있습니다.**

이 쪽은 그 사람에게 「그 비용은 이미 들어 둔 운전자보험에서
나옵니다」라고 말해 주고, **증권 사진 한 장을 보내게** 만드는
것이 할 일입니다.

## 2. 분위기 — 가장 중요합니다

**전문성과 신뢰.** 법률 사건은 큰 결정이라
가볍거나 떠들썩하면 오히려 전화가 끊깁니다.

- **차분하고 절제된 고급스러움.** 병원·로펌의 품격.
- **과장 금지.** 느낌표, 「최고」, 「100%」, 빨간 경고색,
  카운트다운, 「지금 바로!」 같은 장치는 **쓰지 마세요.**
- 흰 여백을 넉넉히. 글자 사이가 답답하지 않게.
- 애니메이션은 **스크롤에 따라 조용히 나타나는 정도**만.

## 3. 색과 글꼴 — 아래 값을 그대로 쓰세요

법인 홈페이지와 같은 값입니다. 바꾸지 마세요.

```css
--paper:     #fcfcfb;   /* 기본 바탕 (노란기 없는 오프화이트) */
--paper-2:   #f1f1ef;   /* 구간을 번갈아 칠할 때 */
--ink:       #17171a;   /* 본문 글자 */
--ink-soft:  #4a4a4f;
--ink-faint: #8a8a90;
--line:      #e2e2e0;   /* 선 */
--gold:      #8a7248;   /* 밝은 바탕의 아주 좁은 강조 */
--gold-soft: #c6ab7f;   /* 어두운 구간 전용 */
--dark:      #141416;   /* 어두운 구간 바탕 */
--cream:     #e4d5b7;   /* 어두운 바탕 위 제목 */
--kakao:     #fee500;   /* 카톡 버튼. 이 색은 바꾸면 안 됨 */
```

**색은 아껴 씁니다.** 금색은 눈썹글씨(영문 소제목)와
아주 좁은 선에만. 넓은 면을 금색으로 칠하지 마세요.
**색을 가진 유일한 넓은 자리는 카카오톡 버튼입니다.**

글꼴은 구글폰트에서 불러오세요.

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,300;0,400;0,500;1,300&family=Noto+Serif+KR:wght@200;300;400;500&family=Noto+Sans+KR:wght@300;400;500;700&display=swap">
```

- **큰 제목** — Noto Serif KR (가늘게, 200~400). 영문은 Cormorant Garamond.
- **본문** — Noto Sans KR 300~400.
- 한글 줄바꿈이 어색하지 않게 `word-break: keep-all;`
  `text-wrap: pretty;` 를 쓰세요.

## 4. 짜임새

위에서 아래로 이 순서입니다. 각 절은 화면 하나만큼
넉넉한 위아래 여백(80~140px)을 두세요.

1. **머리말** — 어두운 바탕(#141416). 큰 제목 + 한 문단 +
   버튼 셋 + 그 아래 작은 글씨로 실적과 담당자
2. 지금 머릿속에 있는 질문 셋
3. 왜 내 사고는 보험으로 안 끝났나 — **법조문 인용 칸**
4. 그래서 어디까지 갈 수 있나 — **법조문 인용 칸**
5. **비용은 운전자보험에서 나옵니다** — 표
6. **증권에서 두 줄만 확인하십시오** — 표 + **버튼 둘**
7. 서두르지 마십시오 — 네 가지
8. 보험이 안 되는 경우 — **주의 칸**
9. 저희가 하는 일 — 다섯
10. 맡는 사람 — 표
11. 자주 묻는 것 — 열고 닫히는 목록
12. 마지막 — 어두운 바탕 + **버튼 셋**

## 5. 꼭 넣어야 하는 장치

**① 아래 고정 막대 (휴대폰에서만)**
화면 아래에 늘 붙어 있는 막대. 「전화 상담」과
「카톡 상담」 두 칸. 스크롤해도 사라지지 않게.

**② 버튼은 세 가지만**
- `전화 상담` — `<a href="tel:02-597-4977">`
- `카톡으로 증권 보내기` — 카카오 노란색(#fee500),
  글자는 #1b1508
- `상담 신청서` — 테두리만 있는 버튼

**③ 법조문 인용 칸**
왼쪽에 금색 세로선(2px), 연한 바탕(#f6f4ef),
위에 작은 글씨로 조문 이름.

**④ 강조 칸**
어두운 바탕(#141416)에 크림색 글자. 위와 왼쪽에만
금색 선. 한 문장만 넣습니다. 쪽 전체에 **두세 번만** 쓰세요.

**⑤ 주의 칸**
아주 연한 분홍 바탕(#fdf5f5), 왼쪽에 붉은 기가 도는
세로선. 「보험이 안 되는 경우」에만 씁니다.

**⑥ 표**
세로줄은 긋지 말고 **가로선만** 얇게. 머리줄은 연한 회색.
휴대폰에서는 좌우로 밀 수 있게 감싸 주세요.

## 6. 반드시 지킬 것

- **휴대폰 먼저.** 폭 390px에서 가로 스크롤이 생기면 안 됩니다.
- 버튼은 손가락으로 누를 수 있게 **높이 48px 이상.**
- 글자 크기는 본문 16~17px, 줄 간격 1.9 이상.
- **결과를 약속하는 말을 쓰지 마세요.** 「무죄」 「승소」
  「해결」 「보장」 「반드시」는 금지입니다. 변호사법 위반입니다.
- 「전문」은 **「대한변협 등록 형사법 전문변호사」**에만 쓰세요.
  다른 데 붙이면 안 됩니다.
- 글은 제가 드린 본문을 **그대로** 쓰세요. 바꾸거나
  보태지 마세요. 특히 숫자와 조문은 한 글자도 고치지 마세요.
