# 법인 이름이나 홈페이지 주소를 바꾸실 때

2026-10-29 작성.

**둘은 전혀 다른 일입니다.** 하나는 쉽고, 하나는 비쌉니다.

| | 바꿀 수 있나 | 검색 손해 |
|---|---|---|
| **법인 이름** (법무법인 유일 → ○○) | 됩니다 | 작습니다 |
| **홈페이지 주소** (yuillawfirm.com → ○○) | **됩니다** | **큽니다** |

---

## 1. 법인 이름만 바꾸기 — 어렵지 않습니다

### 어디에 적혀 있나

| 글자 | 몇 곳 |
|---|---|
| `법무법인 유일` | 552곳 |
| `YUIL LAW FIRM` | 61곳 |

많아 보이지만 **한 번에 바꿉니다.** 제가 하면 반나절 일입니다.

### 검색은 어떻게 되나

**주소가 그대로면 크게 다치지 않습니다.**
검색엔진이 쌓아 둔 신뢰는 **이름이 아니라 주소에** 붙어 있습니다.
쪽들은 그대로 남고, 새 이름을 몇 주에 걸쳐 다시 배웁니다.

다만 **옛 이름으로 찾던 분들**이 한동안 헤맵니다.
지금 들어오시는 분의 대부분이 이름 검색입니다.

| | 들어온 사람 |
|---|---|
| 법무법인 유일 · 법무법인유일 등 | **217분** |
| 분야 · 자리로 찾은 분 | 나머지 |

그래서 이름을 바꾸시면 **한동안 들어오는 분이 줍니다.**
첫 화면에 「옛 이름에서 바뀌었습니다」 한 줄을 한두 달 두면
덜 잃습니다. 말씀해 주시면 넣어 드리겠습니다.

### 함께 고쳐야 하는 것

- 사업자등록번호 줄, 바닥글, 로고 글자(`YUIL`)
- 네이버 플레이스 · 구글 비즈니스 프로필
- 명함 · 간판 · 기존 광고

---

## 2. 홈페이지 주소 바꾸기 — 됩니다. 다만 비쌉니다

**못 바꾸는 것이 아닙니다.** 주소는 가비아에서 산 것이고,
새로 사서 옮기면 됩니다.

### 기술적으로 할 일

| | |
|---|---|
| `CNAME` 파일 | 새 주소로 |
| 가비아 DNS | 새 주소를 깃허브로 |
| 쪽 안의 주소 | **596곳** (63개 파일) |
| `sitemap.xml` · `robots.txt` | 새 주소로 |

이것도 제가 한 번에 바꿉니다. **여기까지는 어렵지 않습니다.**

### 비싼 것은 검색입니다

**검색엔진이 쌓아 둔 것이 전부 옛 주소에 붙어 있습니다.**

| | 지금 |
|---|---|
| 구글 색인 | 55쪽 |
| 네이버 노출 | 8,200번 |
| 네이버 클릭 | 260 |

주소를 바꾸면 **새 주소는 아무것도 없는 상태에서 시작**합니다.

옛 주소에서 새 주소로 **「영구 이전(301)」**을 걸어야 넘어갑니다.
그래도 **구글은 몇 주, 네이버는 몇 달** 걸립니다.

### ⚠️ 301 을 거는 것이 생각보다 까다롭습니다

지금 홈페이지는 깃허브에서 **한 주소만** 서비스합니다.
그래서 옛 주소를 살려 두고 넘겨주는 일은
**가비아의 포워딩 기능이나 다른 곳**에서 해야 합니다.

> **가비아 포워딩이 「영구 이전(301)」인지 먼저 확인하십시오.**
> 「임시(302)」나 「프레임」 방식이면 검색이 안 넘어갑니다.
> 저는 확인하지 못했습니다.

### 구글은 도구가 있습니다

서치콘솔에 **「주소 변경」**이 있습니다. 순서는 이렇습니다.

1. 새 주소를 서치콘솔에 **새로 등록**하고 소유 확인
2. 옛 주소 → 새 주소로 **301** 을 먼저 걸어 둔다
3. 옛 주소 쪽 설정에서 **주소 변경** 신청
4. 구글이 301 이 잘 걸렸는지 검사하고 이전을 시작

**쪽 하나하나를 짝지어** 넘겨야 합니다.
전부 새 첫 화면으로 몰아 보내면 구글이 오류로 봅니다.

**301 은 최소 1년** 유지하십시오.

### 네이버는 도구가 없습니다

같은 기능을 찾지 못했습니다.
**사이트맵을 새로 내고 기다리는 수밖에** 없습니다.
지금 네이버에 쪽이 한 장만 들어가 있는 것을 생각하면,
**몇 달이 걸릴 수 있습니다.**

### 홈페이지 밖에서 고쳐야 하는 것

명함 · 간판 · 네이버 플레이스 · 구글 비즈니스 프로필 ·
카카오톡 채널 · 기존 광고 · 다른 사이트에 걸린 링크.

## 3. 제 권고

### 이름이 바뀌어도 **주소는 그대로 두십시오**

**주소가 법인 이름과 같아야 할 이유가 없습니다.**
`yuillawfirm.com` 은 이미 검색엔진이 1년 가까이 지켜본 주소이고,
그 신뢰는 돈으로 살 수 없습니다.

이름만 바꾸고 주소를 그대로 두시면
**잃는 것이 거의 없습니다.**

### 꼭 바꾸셔야 한다면

1. **새 주소를 먼저 사 두고** 한두 달 묵혀 두십시오
2. 홈페이지를 다 고친 뒤 **같은 날** 301 을 겁니다
3. 구글 서치콘솔 **주소 변경** 신청
4. 네이버에 새 주소 등록 + 사이트맵 제출
5. 네이버 플레이스 · 구글 비즈니스 프로필 주소 수정
6. **1년은 옛 주소를 살려 두십시오**

### 바꾸기 가장 좋은 때

**지금처럼 검색이 막 오르기 시작할 때가 아니라, 되도록 빨리**입니다.
쌓인 것이 적을수록 잃을 것도 적습니다.
바꾸실 생각이 조금이라도 있으시면 **미루지 마십시오.**
