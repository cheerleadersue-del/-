# 민사 중심에서 형사 중심으로 되돌리기

2026-09-15, 홈페이지를 잠시 **민사 중심**으로 바꿨습니다.
나중에 **형사 중심**이던 모습으로 되돌리기 위한 기록입니다.

이 문서는 홈페이지에 나오지 않습니다. `docs` 폴더는 배포에서 빠집니다.


## 돌아갈 자리

```
baebcc0
```

커밋 메시지는 "오시는 길에 회생 · 등기 직통을 넣었다" 입니다.


## 되돌리는 법

터미널에서 저장소 폴더에 들어간 뒤 아래 두 줄이면 됩니다.

```sh
git checkout baebcc0 -- .
git commit -m "형사 중심 모습으로 되돌렸다"
```

`git checkout baebcc0 -- .` 은 그때의 **파일 내용만** 지금 자리로 가져옵니다.
그 뒤에 한 일들이 기록에서 사라지지 않으므로, 되돌린 것을 다시 되돌릴 수도 있습니다.

되돌린 뒤 `git push` 하시면 홈페이지에 반영됩니다.


## 그때(형사 중심)와 지금(민사 중심)의 차이

| | 형사 중심 (baebcc0) | 민사 중심 (지금) |
|---|---|---|
| 첫 화면 문구 | 증거주의 / 수사 · 재판 대응 | 문구 없이 로고와 법인 이름 |
| 전담센터 | 형사 · **교통형사** · 민사 · 가사 · 회생 · 공증.등기 | **민사** · 형사 · 가사 · 회생 · 공증.등기 |
| 민사 분야 차례 | 의료사고 · 부동산 · 대여금 · 계약분쟁 · 전세사기 · 손해배상 | 부동산 · 대여금 · 계약분쟁 · 전세사기 · 손해배상 · 의료사고 |
| 정호길 분야 | 강력범죄 · 마약 · 교통사고 | 일반민사 · 건설 · 부동산 · 형사 · 강력범죄 |
| 양진희 분야 | 강력범죄 · 성범죄 | 일반민사 · 건설 · 부동산 |
| 양진희 상세이력 | 14줄 (변호사시험 · 북경이공대 · Golden Gate 포함) | 11줄 (그 셋을 뺀 것) |

교통형사는 **전담센터 목록과 상단 메뉴에서** 뺐습니다.
그 칸이 홈페이지에서 바깥 사이트(교통형사전문로펌.com)로 가는 **하나뿐인 문**이었으므로,
지금은 홈페이지 어디에서도 그 사이트로 갈 수 없습니다.
바깥 사이트 자체는 그대로 떠 있고, 되돌리면 링크도 함께 돌아옵니다.

칸에 쓰던 사진 `assets/center-traffic.webp` 은 지우지 않고 남겨 두었습니다.
되돌릴 때 그대로 쓰입니다.

세부 페이지의 **내용은 하나도 건드리지 않았습니다.** 차례와 표시만 바뀌었습니다.


## 되돌릴 때 같이 보실 것
