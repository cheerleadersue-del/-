## 전화 고르는 칸

**「대표전화」 「무료상담」처럼 창구를 가리지 않는 단추**를 누르면
여섯 번호가 펼쳐집니다.

**창구가 적힌 단추**(「공증 무료상담」 · 「교통 무료상담」 …)는
**그대로 바로 걸립니다.** 그 쪽에 오신 분은 이미 어디로 걸지
아시는 분이라, 한 번 더 고르게 하면 성가십니다.

창구가 적힌 단추만 있는 쪽(공증 쪽 같은)에서도 다른 번호가
필요하실 수 있어, **바닥글에 「다른 번호 보기」** 를 한 줄 두었습니다.

## 고치는 순서

### 1. 목록을 고칩니다

`main.js` 에서 `const phones = [` 를 찾으십시오.

```js
const phones = [
  { label: "대표", tel: "02-563-0625", note: "어디로 걸지 모르실 때" },
  …
];
```

| | |
|---|---|
| `label` | 목록에 크게 보이는 이름 |
| `tel` | 실제로 걸리는 번호 |
| `note` | 그 아래 작은 글씨 |

### 2. ⚠️ 쪽에 박힌 번호도 함께 고칩니다

**목록만 고치면 반쪽입니다.** 같은 번호가 이런 자리에도 있습니다.

- 머리띠 오른쪽 (`head-call`)
- 아래 막대 · 오른쪽 빠른 상담 단추
- 본문의 「무료상담전화」 단추
- 첫 화면 **오시는 길**
- 바닥글 주소 줄

**어느 번호가 어디에 있는지 찾는 법** — 홈페이지 폴더에서

```
grep -rn "02-6254-8485" --include=*.html --include=*.js .
```

저에게 **「○○ 번호를 △△로 바꿔 주세요」** 라고만 하셔도 됩니다.
한 번에 다 바꿔 드립니다.

### 3. 올립니다

`main.js` 를 고치셨으면 올리기 전에 한 줄 더 치십시오.

```
node tools/bump-assets.mjs
node tools/make-lawyer-pages.mjs
```

## ⚠️ 아직 정리되지 않은 것

쪽 **서른여덟 장**의 머리띠에 **「대표전화 02-6254-8485」** 라고
적혀 있습니다. 그런데 법인에서 알려 주신 목록으로는
**02-6254-8485 는 형사 · 민사 센터**이고, 대표는 02-563-0625 입니다.

**이름과 번호가 어긋나 있습니다.** 고르는 칸에는 둘 다 바르게
나오지만, 머리띠는 그대로입니다.

둘 중 하나를 정해 주십시오.

| | |
|---|---|
| **가** | 머리띠 번호를 **02-563-0625** 로 바꾼다 |
| **나** | 머리띠 이름을 **「무료상담」** 으로 바꾼다 (번호는 그대로) |

**「나」를 권합니다.** 02-6254-8485 는 그동안 광고와 검색결과에
실어 온 번호라, 바꾸면 그 번호로 기억하신 분이 헤맵니다.
