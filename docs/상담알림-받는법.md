# 상담 신청 알림 받는 법

상담이 들어왔을 때 **휴대폰에 바로 뜨게** 하는 방법입니다.

## 먼저 — 구글 시트만으로는 알림이 안 옵니다

구글 시트에도 알림 기능(도구 → 알림 규칙)이 있지만,
**사람이 직접 편집할 때만 작동합니다.** 스크립트가 자동으로 넣은 줄에는 뜨지 않습니다.

시트는 **모아서 관리하는 장부**로 쓰고, 알림은 아래 방법으로 따로 받으셔야 합니다.

---

## 세 가지 방법 비교

| | 비용 | 설정 | 휴대폰 알림 | 권장 |
|---|---|---|---|---|
| **1. 이메일** | 무료 | 1분 | 메일 앱 푸시 | 우선 이것부터 |
| **2. 문자(SMS)** | 건당 약 20원 | 20분 | 문자로 확실히 | 놓치면 안 될 때 |
| **3. 카카오 알림톡** | 건당 약 10원 + 심사 | 며칠 | 카톡으로 | 권하지 않음 |

**1번을 먼저 켜시고, 부족하면 2번을 더하세요.**
3번(알림톡)은 카카오 비즈니스 채널 개설과 템플릿 사전심사가 필요해
상담 알림 용도로는 품이 너무 많이 듭니다.

---

## 1. 이메일 알림 (무료 · 1분)

1. [app.netlify.com](https://app.netlify.com) → 사이트 → **Forms** 탭
2. **Settings and usage** → **Form notifications** → **Add notification**
3. **Email notification** 선택
4. Email to notify → `psg8656@naver.com` → **Save**

### 휴대폰에 뜨게 하려면

메일이 왔다는 사실이 화면에 떠야 의미가 있습니다.

- 네이버 메일 앱을 설치하고 **알림 허용**을 켜세요
- 아이폰은 설정 → 알림 → 네이버 메일 → **알림 허용** + **잠금 화면 표시**
- 안드로이드는 설정 → 앱 → 네이버 메일 → 알림 → 켜기

메일 앱 알림만 잘 켜두면 문자만큼 빠릅니다. **먼저 이걸로 며칠 써보세요.**

---

## 2. 문자(SMS) 알림 (건당 약 20원 · 20분)

코드는 이미 저장소에 들어 있습니다 (`netlify/functions/submission-created.js`).
**API 키만 넣으시면 바로 동작합니다.**

### 2-1. 솔라피 가입

1. [solapi.com](https://solapi.com) 가입
2. **발신번호 등록** — 사무실 번호 `02-567-4377` 를 등록하고 인증합니다
   (통신사 규정상 등록·인증된 번호로만 발송할 수 있습니다)
3. **캐시 충전** — 1만원이면 약 500건입니다
4. **API Key / API Secret** 발급 — 개발/연동 → API Key 관리

### 2-2. Netlify에 키 넣기

Netlify → 사이트 → **Site configuration** → **Environment variables** → **Add a variable**

네 개를 각각 추가합니다.

| Key | Value | 설명 |
|---|---|---|
| `SOLAPI_KEY` | 발급받은 API Key | |
| `SOLAPI_SECRET` | 발급받은 API Secret | 절대 공개하지 마세요 |
| `SMS_FROM` | `025674377` | 등록한 발신번호, 숫자만 |
| `SMS_TO` | `01012345678` | 받으실 휴대폰, 숫자만 |

넣은 뒤 **Deploys → Trigger deploy → Deploy site** 로 한 번 다시 배포해야 적용됩니다.

### 2-3. 시험

홈페이지에서 상담 신청을 한 번 제출해 보세요. 이런 문자가 옵니다.

```
[법무법인 유일] 상담신청 도착
홍길동 / 01012345678
내용은 관리화면에서 확인하세요.
```

### 상담 내용을 문자에 안 넣은 이유

일부러 뺐습니다. 사건 내용이 문자에 담기면
**통신망과 휴대폰 잠금화면 알림창에 그대로 남습니다.**
성범죄·형사 사건 상담이라면 그 자체가 위험합니다.

누가 언제 신청했는지만 알리고, 내용은 관리화면에서 보시는 편이 안전합니다.

### 안 될 때

Netlify → **Logs** → **Functions** → `submission-created` 에서 기록을 봅니다.

| 기록 | 원인 |
|---|---|
| `문자 발송 설정이 없어 건너뜁니다` | 환경변수 4개 중 빠진 것이 있음 |
| `문자 발송 401` | API Key/Secret 오타 |
| `문자 발송 400` | 발신번호 미등록, 또는 번호에 하이픈이 들어감 |
| 아무 기록도 없음 | 환경변수 넣고 재배포를 안 했음 |

### 여러 명이 받으려면

`SMS_TO` 에는 한 번호만 넣을 수 있습니다.
여러 분이 받으셔야 하면 알려주세요. 번호 목록을 받도록 코드를 고치겠습니다.
