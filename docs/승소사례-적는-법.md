# 주요 승소사례 — 적기 전에 읽어 주십시오

2026-10-29 작성.

변호사 한 분 쪽에 **「주요 승소사례」** 자리를 만들어 두었습니다.
**지금은 자료가 없어 그 묶음이 화면에 나오지 않습니다.**

자료를 주시면 바로 넣겠습니다. 다만 **광고규정에 선이 있습니다.**
먼저 읽어 주십시오.

---

## 1. 제가 지어낼 수 없습니다

지금 홈페이지에 적혀 있는 것은 **「무엇을 다뤘는가」**뿐입니다.

> 수행 — 의료법위반 · 업무상과실치사상 · 사문서위조

**결과가 적혀 있지 않습니다.** 그래서 제가 승소사례를 만들 수 없습니다.
**법인에서 사건을 골라 주셔야 합니다.**

---

## 2. ⚠️ 무엇이 걸리나

**단속이 세졌습니다.** 법무부 변호사징계위원회에 접수된
광고규정 위반 징계가 **2021년 1건 → 작년 88건**으로 늘었습니다
(2026년 7월 보도).

실제로 제재를 받은 것들입니다.

| 이렇게 적었다가 | 어떻게 됐나 |
|---|---|
| 「1만1347건의 성공사례」 | 과태료 처분, 취소 청구 **기각** |
| 「2배 이상 타 로펌 대비 높은 성공률」 | 문제가 됨 |
| 승소 가능성을 단정해 말함 | 징계 — 그 사건들은 **모두 패소**로 끝남 |

근거는 **변호사법 제23조 제2항**입니다.
객관적 사실을 **과장**하거나 사실의 **일부를 누락**해
소비자를 오해하게 할 우려가 있는 광고를 금지합니다.

> **정확한 변호사업무광고규정 제4조 원문은 확인하지 못했습니다.**
> 대한변호사협회 홈페이지에서 현행 조문을 직접 보시는 것이 정확합니다.
> 제가 본 것은 보도와 판결 요지뿐입니다.

---

## 3. 이렇게 적으면 됩니다

### ✅ 괜찮은 것

> **마약류관리법위반(향정) — 기소유예**
> 초범이고 투약 횟수가 적은 사건이었습니다.
> 자진 신고와 치료 경과를 자료로 내어 기소유예를 받았습니다.
> 2025년 · 서울중앙지검

사실 그대로이고, 어떤 사건이었는지와 무엇을 했는지가 있습니다.

### ❌ 걸리는 것

| 쓰면 안 되는 말 | 왜 |
|---|---|
| 승소율 95% | 숫자로 기대를 만듭니다 |
| 성공사례 1,000건 | 위 판결에서 문제가 된 바로 그 형태입니다 |
| 반드시 · 100% · 무조건 | 단정입니다 |
| 업계 최고 · 최다 · 1위 | 근거를 댈 수 없습니다 |
| 의뢰인 실명 · 상호 | 동의 없이는 안 됩니다 |

---

## 4. 저에게 보내 주실 것

사건 하나에 **이 네 가지**면 됩니다.

```
1. 죄명 또는 사건 종류   예) 마약류관리법위반(향정)
2. 결과                 예) 기소유예 / 무죄 / 일부 승소
3. 무엇을 했나 (두세 줄)  예) 자진 신고와 치료 경과를 자료로 제출
4. 때와 곳              예) 2025년 · 서울중앙지검
```

**사건번호와 의뢰인 이름은 보내지 마십시오.** 쓰지 않습니다.

### 몇 건이 좋은가

**한 분당 세 건에서 다섯 건**이 좋습니다.
많이 늘어놓으면 「건수 자랑」으로 읽혀 오히려 위험합니다.

---

## 5. 넣으면 자동으로 따라오는 것

사례마다 아래 한 줄이 **자동으로** 붙습니다. 지우지 마십시오.

> 사건의 결과는 사실관계와 증거에 따라 달라집니다.
> 위 사례가 같은 결과를 보장하지 않습니다.

---

## 6. 어디에 적히나

`main.js` 의 `attorneys` 배열, 그분의 `wins` 에 적습니다.

```js
wins: [
  {
    title: "마약류관리법위반(향정) — 기소유예",
    body: "초범이고 투약 횟수가 적은 사건이었습니다. 자진 신고와 " +
          "치료 경과를 자료로 내어 기소유예를 받았습니다.",
    meta: ["2025년", "서울중앙지검"]
  }
]
```

적으신 뒤 홈페이지 폴더에서 **한 줄만** 치시면 쪽에 반영됩니다.

```
node tools/make-lawyer-pages.mjs
```

**자료만 주시면 제가 다 해 드립니다.** 위 형식은 참고용입니다.
