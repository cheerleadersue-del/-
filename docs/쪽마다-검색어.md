## 고치실 때 지켜야 하는 것

1. **스무 개를 넘기지 마십시오.**
   서른 개가 넘으면 검색엔진이 무차별로 채운 쪽으로 보고
   **이 줄을 통째로 무시**할 수 있습니다. 지금은 쪽마다 5~15개입니다.

2. **본문에 있는 말만 적으십시오.**
   말을 더하실 때는 본문에도 한 번 들어가게 해 주십시오.

3. **「전문」은 대한변협에 등록한 분야에만.**
   증서로 확인된 것은 **형사법**(정호길, 등록 제2026-657호, 2026. 7. 27.)입니다.
   의료는 2026-10-09 에 법인에서 확인해 주셨습니다.
   그래서 센터 검색어에는 「전문」을 넣지 않았습니다.

4. **같은 말을 여러 쪽에 넣어도 됩니다.**
   교통사고 열세 쪽에 「교통사고」가 모두 들어 있는 것처럼요.
   다만 **그 쪽의 주제가 맨 앞**에 와야 합니다.
