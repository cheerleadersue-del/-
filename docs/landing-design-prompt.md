# 0. 레퍼런스에서 가져올 것 / 버릴 것

## 가져올 것

| | 왜 |
|---|---|
| **설명선(annotation)** | 화면 옆에 가는 선을 긋고 「이게 뭔지」 짚어 주는 장치.<br>**이 쪽의 핵심입니다.** |
| **왼쪽 글 · 오른쪽 그림**이 번갈아 | 길어도 안 지칩니다 |
| 구간마다 **큰 색면**으로 끊기 | 어디까지 읽었는지 알게 됩니다 |
| 작은 영문 머리글(`01. APP DESIGN`) | 우리 쪽에도 이미 있는 장치입니다 |
| **기울여 겹쳐 놓은 화면** | 평면적이지 않고 눈이 갑니다 |

## 버릴 것

| | 왜 |
|---|---|
| **쨍한 파랑** | 법인 홈페이지가 무채색 + 금색입니다.<br>파란 랜딩페이지는 **다른 회사처럼** 보입니다 |
| 일러스트 캐릭터 | 법률 사건에 안 맞습니다 |
| 포트폴리오 말투<br>(`작업연도` `기여도`) | 우리는 의뢰인에게 말합니다 |

## ★ 핵심 아이디어

> RUNFLOW 는 **앱 화면**에 선을 긋고 설명합니다.
> 우리는 **보험증권**에 선을 긋고 설명합니다.
>
> 「변호사선임비용**(경찰조사포함)**」 ← 여기에 선을 그어
> 「이 괄호가 있으면 지금 선임하셔도 됩니다」라고 짚습니다.
>
> **이 쪽의 행동 지시가 「증권 사진 보내기」이므로,
> 증권을 보여 주는 것이 가장 강력합니다.**

## 색 — 셋 중 하나를 골라 주십시오

| | 어떻게 | 제 생각 |
|---|---|---|
| **가** | 지금 홈페이지 그대로<br>(오프화이트 · 먹색 · 금색) | **가장 안전.** 법인과 하나로 보입니다 |
| **나** | 거기에 **진한 남색**(#1b2a41)을<br>큰 색면으로 추가 | **권합니다.** 레퍼런스의 기운을 살리면서<br>법인과 따로 놀지 않습니다 |
| **다** | 레퍼런스처럼 **쨍한 파랑** | 눈에 띄지만 **법인과 어긋납니다** |

**아래 프롬프트는 「나」로 써 두었습니다.** 바꾸실 거면
`#1b2a41` 자리에 `#141416`(가) 을 넣으시면 됩니다.

## 공통 문구 (세 번 모두 앞에 붙이세요)

```

## 참고하는 스타일
깔끔한 앱 포트폴리오 케이스 스터디 레이아웃입니다.
왼쪽에 글, 오른쪽에 화면 목업이 번갈아 나옵니다.
목업 옆에는 아주 가는 선을 긋고 그 끝에 작은 설명 글이 붙습니다.
구간마다 큰 색면으로 바탕이 바뀝니다.

## 색 (이 값만)
- 기본 바탕 #fcfcfb
- 교대 바탕 #f1f1ef
- 큰 색면 #1b2a41 (진한 남색)
- 가장 어두운 구간 #141416
- 본문 글자 #17171a, 흐린 글자 #8a8a90
- 선 #e2e2e0 (머리카락처럼 얇게)
- 금색 강조 #8a7248 (아주 좁은 자리에만)
- 남색/검정 위 글자 #e4d5b7
- 노란색 #fee500 은 버튼 딱 하나에만

색을 아껴 씁니다. 알록달록하면 안 됩니다.
채도 높은 파랑, 초록, 빨강을 쓰지 마세요.

## 분위기
차분하고 절제된 고급스러움. 대형 로펌의 품격.
느낌표, 빨간 경고색, 할인 배너, 카운트다운, 캐릭터 일러스트는
절대 넣지 마세요. 여백이 아주 넉넉합니다.

## 글꼴 느낌
큰 제목은 아주 크고 가는 한글 명조.
본문은 가는 한글 고딕에 줄 간격 넓게.
구간마다 위에 아주 작은 영문 대문자를 자간 넓게.

## 글자에 대하여
한글이 정확하지 않아도 됩니다. 짜임새만 볼 것입니다.
글자 자리는 흐린 덩어리로 표현해도 됩니다.

가로 1440px 데스크톱 화면입니다.
```

# 3. 제가 할 일

그림을 주시면

1. **설명선은 제가 HTML·CSS로 긋습니다.** 그림에 넣지 마십시오.
   글자가 깨지고, 나중에 못 고칩니다.
2. 진짜 글자(`docs/랜딩-본문만.md`)를 넣습니다.
3. 법인 색 · 글꼴 · 버튼을 그대로 씁니다.
4. 휴대폰 390px에서 넘치는 곳을 잡습니다.
5. 제목 · 설명 · 검색어를 넣습니다.
6. `traffic-insurance.html` 로 올립니다.

**그림이 하나도 없어도 쪽은 만들 수 있습니다.**
남색과 먹색 바탕에 글자만 나옵니다. 먼저 만들어 두고
그림이 오는 대로 끼워 넣어도 됩니다.

# 4. 정해 주실 것

1. **색은 가 · 나 · 다 중 어느 쪽입니까.**
   (프롬프트는 「나 — 진한 남색」으로 써 두었습니다)
2. **설명선을 어디에 긋습니까.** 제 생각은 이 넷입니다.
   - 증권의 「변호사선임비용(경찰조사포함)」 → 「이 괄호가 전부입니다」
   - 증권의 「교통사고처리지원금」 → 「합의금이 여기서 나옵니다」
   - 증권의 「벌금」 → 「대인 2,000만원 한도인 상품이 많습니다」
   - 증권 맨 위 → 「자동차보험이 아니라 운전자보험입니다」
3. **그림 없이 먼저 만들어 둘까요,** 그림을 기다릴까요.
