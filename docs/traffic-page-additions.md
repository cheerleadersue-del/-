# 새 절 ① — 12대 중과실 열두 가지

### 제목
> ## 12대 중과실 열두 가지

### 들머리 한 줄
> 이 열둘에 해당하면 종합보험에 가입되어 있어도 기소됩니다.

### 표

| | | |
|---|---|---|
| 1 | 신호 · 지시 위반 | |
| 2 | 중앙선 침범, 고속도로 횡단 · 유턴 · 후진 | |
| 3 | 제한속도 **20km/h 초과** | 20km가 기준입니다 |
| 4 | 앞지르기 방법 · 금지시기 · 금지장소 · 끼어들기 위반 | |
| 5 | 철길건널목 통과방법 위반 | |
| 6 | 횡단보도 보행자 보호의무 위반 | |
| 7 | 무면허운전 | |
| 8 | 음주 · 약물 운전 | |
| 9 | 보도 침범 · 보도 횡단방법 위반 | |
| 10 | 승객 추락방지의무 위반 | |
| 11 | 어린이보호구역 안전운전의무 위반(어린이 상해) | 민식이법 |
| 12 | 화물 고정조치 위반 | |

### 표 아래 한 문단

> **위반했다고 바로 걸리는 것은 아닙니다.**
> 조문은 「다음 각 호의 어느 하나에 해당하는 행위로 **인하여**
> 같은 죄를 범한 경우」라고 정하고 있습니다.
> 위반과 사고 사이에 **인과관계**가 있어야 합니다.
> 속도는 **20km/h가 기준**입니다. 19km는 해당이 없습니다.

### 그 아래 한 문단 — 사람이 안 다친 경우

> **단서는 「치상죄」만 대상으로 합니다.**
> 사람이 다치지 않은 접촉사고는 음주 · 무면허였더라도
> 이 단서가 적용되지 않습니다.
> 다만 **음주운전 · 무면허운전 그 자체**는 도로교통법으로
> 따로 처벌됩니다.

### 법조문 칸 (law-box)

> **교통사고처리 특례법 제3조 제1항**
> 차의 운전자가 교통사고로 인하여 「형법」 제268조의 죄를 범한
> 경우에는 **5년 이하의 금고 또는 2천만원 이하의 벌금**에 처한다.

> 죄명은 **「교통사고처리특례법위반(치상)」**입니다.

### 강조 칸 (key)

> 보험에 들어 있어도 **피해자가 중상해를 입으면 기소됩니다.**
> 헌법재판소가 2009년에 그 부분을 위헌으로 결정했습니다
> (2005헌마764 · 2008헌마118 병합).

# 새 절 ② — 운전자보험으로 되는 것

### 제목
> ## 운전자보험으로 되는 것

### 들머리 한 줄
> 자동차보험과 다른 보험입니다. 비용을 메우는 쪽입니다.

### 표

| 특약 | 무엇을 | 얼마까지 |
|---|---|---|
| **변호사선임비용** | 변호사를 선임한 실제 비용 | 특약마다 다릅니다 |
| **교통사고처리지원금** | 피해자와의 **형사합의금** | 2,000만 ~ 1억원 |
| **벌금** | 선고된 벌금 | 대인 2,000만원 · 스쿨존 3,000만원 |

### 소제목 — 언제부터 나오나

| 특약 이름 | |
|---|---|
| 「변호사선임비용」 | **기소된 뒤**부터 |
| 「변호사선임비용**(경찰조사포함)**」 | **경찰 조사 단계**부터 |

> **특약 이름 끝의 괄호가 시점을 정합니다.**
> 괄호가 없으면 경찰 단계에서 쓴 선임비는 나오지 않습니다.
> 증권을 가져오시면 그 자리에서 확인해 드립니다.

### 소제목 — 합의금 특약은 요건이 있습니다

> 피해자가 **중상해**이거나 **42일 이상 치료 진단**을 받아야
> 합니다(피해자 1명 기준). 상품에 따라 **상해급수 1~3급**입니다.
>
> **대개 내가 먼저 합의금을 내고 한도 안에서 돌려받는 구조**입니다.
> 보험사가 피해자에게 직접 보내지 않습니다.
>
> **요건을 모르고 합의하면 합의는 했는데 보험금은 못 받습니다.**

### 강조 칸 (key)

> **불송치됐다고 지원금을 못 받는 것이 아닙니다.**
> 금융감독원은 보험사가 불송치 결정을 이유로 지급을 거절한
> 사건에서 **거절이 부당**하다고 판단했습니다(2026. 5. 13.).
> 거절 통보를 받고 포기하신 분이 많습니다.

### 경고 칸 (callout-warn) — 안 되는 경우

> **음주 · 무면허 · 뺑소니 · 약물**
>
> 이 넷은 운전자보험 특약이 나오지 않습니다.
> 변호사선임비용도, 벌금도, 합의금도 마찬가지입니다.
> 금융감독원이 그렇게 안내하고 있습니다.
>
> 12대 중과실 중 **7호 무면허**와 **8호 음주**가 여기 해당합니다.
> 이 사건은 보험이 아니라 **양형으로** 다툽니다.

지금
> 자동차보험과 운전자보험의 담보 범위를 확인합니다.
> 형사합의금과 변호사 선임비용의 보장 절차가 여기서 정해집니다.

바꿀 것
> 운전자보험 특약이 **언제부터** 보장하는지를 봅니다.
> 이 시점이 선임 순서와 합의 시점을 정합니다.

→ 「담보 범위」 「보장 절차」가 겹쳐서 하나로 줄였습니다.

## ③ 04절 「합의를 설계한다」

지금
> 누구와 언제 어떻게 만날지, 어떤 문구로 남길지를 정합니다.
> 안 되더라도 시도한 기록이 남아야 합니다.

바꿀 것
> 합의서에 **처벌불원의 뜻과 범위**를 정확히 적습니다.
> 특약의 지급 요건에도 맞춰야 보험금이 나옵니다.

→ 「누구와 언제 어떻게」가 막연해서 **무엇을 하는지**로 바꿨습니다.
