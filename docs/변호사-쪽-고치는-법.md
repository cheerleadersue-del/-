## ⚠️ 쪽 파일을 손으로 고치지 마십시오

네 장은 **`main.js` 의 자료로 찍어 낸 것**입니다.
쪽을 직접 고치시면 다음에 다시 찍을 때 **지워집니다.**

고치실 곳은 **`main.js` 의 `attorneys` 배열** 하나뿐입니다.

---

## 고치는 순서

**1.** `main.js` 를 엽니다. `const attorneys = [` 를 찾습니다.

**2.** 고치실 분의 묶음을 고칩니다.

```js
{
  name: "김제도", role: "변호사",
  field: "의료사고 · 형사 · 민사",      ← 이름 아래 한 줄
  intro: "…",                          ← 사진 옆 소개
  edu:      [ … ],                     ← 학력
  work:     [ … ],                     ← 경력
  cases:    [ … ],                     ← 다룬 사건
  advisory: [ … ],                     ← 자문
  books:    [ … ],                     ← 저서
  wins:     [ … ]                      ← 주요 승소사례
}
```

**3.** 홈페이지 폴더에서 아래 한 줄을 칩니다.

```
node tools/make-lawyer-pages.mjs
```

네 장이 다시 만들어집니다. 제목과 설명이 한도를 넘지 않았는지도
함께 재 줍니다.

**4.** 올립니다.

---

## 어느 묶음이 어디에 나오나

| 묶음 | 쪽에서 | 대문 명단에서 |
|---|---|---|
| `edu` 학력 | **학력** | 카드 줄 |
| `work` 경력 | **경력** | 카드 줄 |
| `books` 저서 | 경력 안에 | 카드 줄 |
| `wins` 주요 승소사례 | **주요 승소사례** | 안 나옴 |
| `cases` 다룬 사건 | **다룬 사건** | 카드 줄 |
| `advisory` 자문 | **자문** | 카드 줄 |

**비어 있는 묶음은 그 자리가 아예 나오지 않습니다.**
예를 들어 지금은 `wins` 가 네 분 모두 비어 있어서,
어느 쪽에도 「주요 승소사례」 칸이 없습니다.

> 대문 명단 카드에 보이는 줄은 위 묶음을 차례로 이어 붙여
> **저절로** 만들어집니다. 따로 적으실 것이 없습니다.

## 주요 승소사례를 넣으실 때

**먼저 `docs/승소사례-적는-법.md` 를 읽어 주십시오.**
광고규정에 선이 있습니다. 잘못 적으면 징계 대상입니다.

---

## 사진을 바꾸실 때

`image` 에 적힌 파일을 `assets/` 에 같은 이름으로 덮어쓰시면 됩니다.

| | |
|---|---|
| 크기 | 세로로 긴 것. **가로 600px 이상** |
| 모양 | **상반신**. 네 분이 같은 크기로 보여야 합니다 |
| 바탕 | 밝은 단색 |

⚠️ **전신 사진을 넣지 마십시오.** 한 분만 전신이면 네 분이
제각각으로 보입니다. 대표님 전신 컷(`lawyer-01-v2.webp`)은
대문 인사말 자리에만 씁니다.

---

## 제목 · 설명 · 검색어를 바꾸실 때

이것만은 `main.js` 가 아니라
**`tools/make-lawyer-pages.mjs` 의 `META`** 에 있습니다.
자료가 아니라 「문구」라서 따로 두었습니다.

바꾸신 뒤 같은 명령을 다시 치시면 됩니다.
**제목 60칸 · 설명 155칸 · 검색어 20개**를 넘기면 화면에
경고가 뜹니다.

---

## 새 변호사를 더하실 때

1. `main.js` 의 `attorneys` 에 묶음을 하나 더합니다.
   `slug` 와 `page` 를 꼭 적으십시오. 없으면 쪽이 안 만들어집니다.
2. `tools/make-lawyer-pages.mjs` 의 `META` 에 같은 `slug` 로
   제목 · 설명 · 검색어 · 맡는 일을 적습니다.
3. 명령을 칩니다.
4. **`sitemap.xml` 에 그 쪽을 더합니다.** 이건 아직 손으로 합니다.

알려 주시면 제가 해 드리겠습니다.
