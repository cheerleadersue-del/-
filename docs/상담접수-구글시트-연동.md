# 상담 신청을 구글 시트에 자동으로 쌓기

상담 신청이 들어오면 **구글 시트에 한 줄씩 자동으로 기록**되게 만드는 방법입니다.
비용은 들지 않고, 한 번만 설정하면 계속 동작합니다.

```
방문자 제출 → Netlify 접수(스팸 거름) → 구글 시트에 기록
                    ↓
                이메일 알림
```

Netlify에도 원본이 그대로 남으므로, 시트가 잘못돼도 기록은 없어지지 않습니다.

---

## 0단계 — 먼저 이것부터 (1분)

시트 연동을 안 하시더라도 **이메일 알림은 꼭 켜세요.**

1. [app.netlify.com](https://app.netlify.com) 로그인
2. 사이트 선택 → 위쪽 **Forms** 탭
3. **Settings and usage** → **Form notifications** → **Add notification**
4. **Email notification** 선택
5. Email to notify 에 `psg8656@naver.com` 입력 → Save

이걸 켜지 않으면 상담이 들어와도 **메일이 오지 않습니다.** Forms 탭에 쌓이기만 합니다.

---

## 1단계 — 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다
2. 이름을 `법무법인 유일 상담접수` 처럼 알아보기 쉽게 바꿉니다
3. 아래쪽 시트 탭 이름을 **`상담접수`** 로 바꿉니다 (이름이 정확해야 합니다)

---

## 2단계 — 스크립트 붙여넣기

1. 그 시트에서 상단 메뉴 **확장 프로그램 → Apps Script**
2. 기존 내용을 **전부 지우고** 아래를 그대로 붙여넣습니다

```javascript
/**
 * 법무법인 유일 — 상담 신청 접수
 * Netlify Forms 의 outgoing webhook 을 받아 시트에 한 줄씩 기록합니다.
 */

// 아무나 기록하지 못하도록 정하는 비밀 문자열입니다.
// 아래 값을 직접 바꾸세요. 영문·숫자 20자 이상을 권합니다.
const SECRET = '여기를_직접_정한_문자열로_바꾸세요';

const SHEET_NAME = '상담접수';
const HEADERS = ['접수시각', '성명', '연락처', '상담내용', '동의', '처리상태', '메모'];

function doPost(e) {
  // 비밀 문자열이 맞지 않으면 무시합니다.
  if (!e || !e.parameter || e.parameter.key !== SECRET) {
    return ContentService.createTextOutput('denied');
  }

  const sheet = getSheet_();

  let body = {};
  try {
    body = JSON.parse(e.postData.contents);
  } catch (err) {
    body = {};
  }

  // Netlify 가 보내는 모양이 몇 가지라 순서대로 찾아봅니다.
  const d = body.data
        || (body.payload && body.payload.data)
        || body.payload
        || body;

  sheet.appendRow([
    new Date(),
    d.name || '',
    "'" + String(d.tel || ''),   // 앞의 0 이 사라지지 않도록 문자로 저장
    d.message || '',
    d.agree ? '동의' : '',
    '신규',
    ''
  ]);

  return ContentService.createTextOutput('ok');
}

function getSheet_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME);

  if (sheet.getLastRow() === 0) {
    sheet.appendRow(HEADERS);
    sheet.getRange(1, 1, 1, HEADERS.length)
         .setFontWeight('bold')
         .setBackground('#f1f1ef');
    sheet.setFrozenRows(1);
    sheet.setColumnWidth(1, 150);   // 접수시각
    sheet.setColumnWidth(4, 420);   // 상담내용
  }
  return sheet;
}

/** 설정이 잘 됐는지 시험하는 버튼입니다. 실행하면 시험용 한 줄이 들어갑니다. */
function 시험삽입() {
  getSheet_().appendRow([
    new Date(), '홍길동', "'010-0000-0000", '시험 삽입입니다.', '동의', '시험', ''
  ]);
}
```

3. **`SECRET` 값을 직접 바꾸세요.** 예: `yuil2026aBcD9x7Kq2mZ`
   이 값은 뒤에서 한 번 더 씁니다. **메모해 두세요.**
4. 저장 (💾 또는 `Ctrl+S`)

### 잘 되는지 먼저 확인

상단 함수 선택창에서 **`시험삽입`** 을 고르고 **실행**을 누릅니다.
권한 승인 창이 뜨면 허용해 주세요. (본인 시트에 접근하는 권한입니다.)
시트에 시험용 줄이 들어가면 성공입니다. 확인 후 그 줄은 지우세요.

---

## 3단계 — 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 ⚙️ → **웹 앱** 선택
3. 설정을 이렇게 맞춥니다

   | 항목 | 값 |
   |---|---|
   | 설명 | `상담접수 수신` |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > "모든 사용자"가 불안하실 수 있지만, 2단계의 비밀 문자열이 맞아야만
   > 기록되므로 아무나 쓸 수 없습니다.

4. **배포**를 누르고 나오는 **웹 앱 URL**을 복사합니다
   `https://script.google.com/macros/s/AKfy.../exec` 형태입니다

---

## 4단계 — Netlify에 연결하기

1. [app.netlify.com](https://app.netlify.com) → 사이트 → **Forms** 탭
2. **Settings and usage** → **Form notifications** → **Add notification**
3. **Outgoing webhook** 선택
4. 아래처럼 채웁니다

   | 항목 | 값 |
   |---|---|
   | Event to listen for | **New form submission** |
   | URL to notify | 3단계 URL 뒤에 `?key=비밀문자열` 을 붙인 주소 |
   | Form | `consult` |

   URL 예시 — **`?key=` 뒤는 2단계에서 정하신 값입니다.**

   ```
   https://script.google.com/macros/s/AKfy.../exec?key=yuil2026aBcD9x7Kq2mZ
   ```

5. **Save**

---

## 5단계 — 시험해 보기

1. 홈페이지 상담 신청 폼에 시험 내용을 넣고 제출합니다
2. 접수 완료 화면이 뜨는지 확인합니다
3. **1분 안에** 구글 시트에 한 줄이 들어오는지 봅니다
4. 메일도 오는지 확인합니다

시트에 안 들어오면 순서대로 확인하세요.

| 증상 | 확인할 곳 |
|---|---|
| Netlify Forms에도 안 보임 | 폼 자체 문제 — 저에게 알려주세요 |
| Forms엔 있는데 시트에 없음 | `?key=` 값이 스크립트의 `SECRET` 과 같은지 |
| 여전히 안 됨 | Apps Script → **실행** 탭에서 오류 기록 확인 |
| 권한 오류 | 3단계에서 "모든 사용자"로 배포했는지 |

---

## 6단계 — 개인정보처리방침 고치기 ⚠️

**이 단계를 빠뜨리지 마세요.**

상담 내용이 구글(미국)로 넘어가므로, 처리방침의 위탁 항목에 이를 적어야 합니다.
지금 `privacy.html` 에는 Netlify만 적혀 있습니다.

연동을 마치신 뒤 **저에게 "시트 연동 끝났어" 라고 알려주시면 제가 고쳐 넣겠습니다.**
직접 하시려면 `privacy.html` 의 5. 위탁 항목 목록에 아래 한 줄을 더하시면 됩니다.

```html
<li><b>Google LLC</b> — 상담 신청 내역의 보관 및 관리 (Google Sheets)</li>
```

## 알아두실 것

**Netlify 무료 요금제는 월 100건까지입니다.**
넘으면 그 달의 제출이 막힙니다. 상담이 늘면 유료 전환이나 다른 방식을 검토해야 합니다.

**시트 접근 권한을 관리하세요.**
의뢰인의 사건 내용이 담기는 문서입니다. 시트를 "링크가 있는 모든 사용자"로 공유하지 마시고,
필요한 직원의 구글 계정만 개별로 추가하세요.

**오래된 기록은 지우세요.**
처리방침에 상담 정보를 **1년 보관 후 파기**한다고 적혀 있습니다.
시트에서도 1년이 지난 줄은 삭제해 주셔야 방침과 실제가 맞습니다.
