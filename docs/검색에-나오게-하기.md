# 검색에 나오게 하기

구글 · 네이버 · 다음에서 이 홈페이지가 검색되게 하는 방법입니다.

두 가지로 나뉩니다.

- **저장소에서 해둔 것** — 이미 해두었습니다. 다시 하실 일 없습니다.
- **대표님이 하셔야 하는 것** — 각 회사에 계정으로 들어가 신청하는 일이라
  제가 대신할 수 없습니다. 아래 순서대로 하시면 됩니다.


## 0. 주소 — 끝났습니다

2026-09-23, 도메인을 연결했습니다.

```
https://yuillawfirm.com/
```

법인 명의 가비아 계정으로 `yuillawfirm.com` 을 사시고,
가비아 DNS 에 A 레코드 네 줄(`@`)과 CNAME(`www`)을 넣으셨습니다.
깃허브 Settings → Pages 의 Custom domain 에도 저장하셨습니다.

홈페이지 쪽 안에 박혀 있던 **옛 주소 116곳을 전부 새 주소로 바꿨습니다.**
검색엔진에게 알려주는 표시(canonical), 카톡 미리보기(og:url · og:image),
사이트맵, robots.txt, 그리고 구조화 데이터까지 함께입니다.

**이제 1번부터 하시면 됩니다.** 이번에 등록하시는 것은 헛일이 되지 않습니다.

**HTTPS 도 끝났습니다.** 2026-09-23, DNS 확인이 통과하고 인증서가
발급되어 **Enforce HTTPS 에 체크**했습니다. 주소창에 자물쇠가 걸리고,
`http://` 로 들어오신 분도 자물쇠가 걸린 주소로 넘어갑니다.

| | 상태 |
|---|---|
| 도메인 구입 (법인 명의) | 끝 |
| 가비아 DNS — A 네 줄 · CNAME | 끝 |
| 깃허브 Custom domain · CNAME 파일 | 끝 |
| 쪽 안의 주소 116곳 교체 | 끝 |
| Enforce HTTPS | 끝 |
| **검색엔진 등록** | **여기부터입니다** |

## 1. 구글

1. <https://search.google.com/search-console> 에 들어가 구글 계정으로 로그인
2. **속성 추가** → **URL 접두어** → 홈페이지 주소를 넣습니다
3. 소유 확인 방법이 여러 개 나오는데 **HTML 태그** 를 고르십시오.
   `<meta name="google-site-verification" content="……">` 같은 줄이 나옵니다.
   **그 줄을 저에게 보내주시면 홈페이지에 넣어 드립니다.**
4. 넣은 것을 올린 뒤 구글 화면에서 **확인** 을 누르십시오
5. 확인되면 왼쪽 **Sitemaps** 에 들어가 `sitemap.xml` 을 넣고 제출

보통 며칠 안에 들어가기 시작하고, 자리를 잡는 데는 몇 주 걸립니다.


## 2. 네이버

1. <https://searchadvisor.naver.com> 에 네이버 계정으로 로그인
2. **웹마스터도구** → **사이트 등록** → 홈페이지 주소를 넣습니다
3. 소유 확인에서 **HTML 태그** 를 고르십시오.
   `<meta name="naver-site-verification" content="……">` 이 나옵니다.
   **그 줄을 저에게 보내주시면 넣어 드립니다.**
4. 확인 뒤 **요청 → 사이트맵 제출** 에 `sitemap.xml` 을 넣으십시오
5. **요청 → 웹페이지 수집** 에 첫 페이지 주소를 한 번 넣어 주시면 더 빠릅니다

네이버는 구글보다 오래 걸립니다. 한 달 정도 보셔야 합니다.


## 3. 다음(카카오)

1. <https://register.search.daum.net/index.daum> 에 들어갑니다
2. **신규 등록** 에서 홈페이지 주소와 연락처를 넣고 신청하십시오
3. 계정 로그인이나 파일 업로드 없이 신청만으로 됩니다

사람이 검토하므로 며칠에서 몇 주 걸립니다.


## 4. 네이버 플레이스 — 가장 중요합니다

**"법무법인 유일" 로 검색하는 분은 대부분 플레이스를 먼저 봅니다.**
웹사이트 검색 순위보다 이쪽이 훨씬 빨리, 훨씬 크게 나옵니다.

1. <https://smartplace.naver.com> 에 로그인
   (이미 등록된 업체라면 **내 업체** 에 나옵니다)
2. **업체정보 수정** → **홈페이지** 칸에 새 주소를 넣으십시오
3. 함께 확인하실 것
   - 대표전화 **02-563-0625** 가 맞는지
   - 주소 · 영업시간(평일 09:00–18:00) · 주차 안내
   - 대표 사진을 새 홈페이지의 것과 맞추기

플레이스가 등록되어 있지 않다면 새로 등록하셔야 합니다.
사업자등록증과 간판 사진이 필요합니다.


## 5. 예전 홈페이지를 어떻게 할지 정하십시오

**이것을 정하지 않으면 두 사이트가 서로를 깎아먹습니다.**

같은 법인 이름으로 된 사이트가 둘이면 검색엔진은 어느 쪽이 진짜인지
판단하지 못합니다. 그래서 둘 다 순위가 낮아집니다.
새 홈페이지만 올린다고 예전 것이 밀려나지 않습니다.

고르실 수 있는 길은 셋입니다.

| | 무엇을 하는가 | 결과 |
|---|---|---|
| **A. 넘기기** (권합니다) | 예전 주소로 들어오면 새 홈페이지로 자동으로 넘어가게 합니다 | 예전 사이트가 쌓아둔 것이 새 홈페이지로 넘어옵니다. 가장 좋습니다 |
| **B. 닫기** | 예전 사이트를 내립니다 | 깨끗하지만, 쌓아둔 것은 버려집니다 |
| **C. 그대로 두기** | 아무것도 안 합니다 | 둘이 계속 경쟁합니다. 권하지 않습니다 |

A를 하시려면 예전 홈페이지를 만든 곳이나 관리하는 곳에
**"301 리다이렉트로 새 주소로 넘겨 달라"** 고 하시면 됩니다.
그쪽에서 무슨 말인지 압니다.

예전 홈페이지 주소를 알려주시면 지금 무엇이 걸려 있는지 확인해 드리겠습니다.
(제 작업 환경에서 바깥 사이트 접속이 막혀 있어 직접 열어보지는 못하지만,
 어떻게 넘기면 되는지는 정리해 드릴 수 있습니다.)


## 6. 그밖에 도움이 되는 것

검색은 "누가 이 사이트를 가리키는가" 를 크게 봅니다.
법인 이름으로 이미 나오는 곳마다 홈페이지 주소를 넣어 두십시오.

- 대한변호사협회 · 서울지방변호사회 회원 정보
- 네이버 지도 · 카카오맵 업체 정보
- 블로그 · 인스타그램 등 운영 중인 계정의 소개란
- 명함 · 사무실 안내문 · 메일 서명


## 저장소에서 해둔 것 (다시 하실 일 없음)

| 무엇 | 하는 일 |
|---|---|
| `sitemap.xml` | 33개 쪽의 목록. 검색엔진이 한 번에 읽습니다 |
| `robots.txt` | 모든 쪽을 찾아가도 된다는 표시와 사이트맵 주소 |
| `canonical` (35장) | 이 쪽의 진짜 주소가 어디인지. 주소가 여러 개로 갈릴 때 하나로 모아줍니다 |
| `og:url` (32장) | 카톡 · SNS 미리보기가 가리킬 주소 |
| 구조화 데이터 | 법인 이름 · 주소 · 전화 · 영업시간 · 다루는 분야를 기계가 읽는 형식으로 |

상담 완료 쪽(`thanks.html`)과 없는 쪽(`404.html`)은 검색에 안 잡히게 해두었고
사이트맵에서도 뺐습니다.


## 주소를 또 바꾸실 때

나중에 주소가 바뀌면 아래 한 줄로 모든 파일이 바뀝니다.
저에게 말씀하시면 해 드립니다.

```sh
grep -rl "yuillawfirm.com" --include=*.html --include=*.xml --include=*.txt . \
  | xargs sed -i 's|https://yuillawfirm.com|https://새주소|g'
```

그리고 저장소 맨 위의 **`CNAME` 파일**도 함께 고쳐야 합니다.
그 파일 한 줄이 깃허브에게 "이 주소로 서비스하라"고 알려줍니다.

## 글을 쓸 때의 원칙 — 용어를 그대로 씁니다

2026-09-24, 대표님 말씀으로 정했습니다.

**어려운 용어를 굳이 쉬운 말로 바꾸지 않습니다. 그 용어를 그대로 쪽에 씁니다.**

이유가 둘입니다.

**하나. 검색은 용어로 들어옵니다.** 찾으시는 분은 「뼈가 안 붙었어요」가 아니라
**「불유합」**, **「골유합 실패」**로 검색합니다. 「해를 가려요」가 아니라
**「일조권 수인한도」**로 검색합니다. 쪽에 그 말이 없으면 그 검색에 걸리지
않습니다. 쉽게 풀어 쓸수록 검색에서는 멀어집니다.

**둘. 법률 사무소의 쪽입니다.** 용어를 정확히 쓰는 것 자체가 신뢰의
표시입니다. 다 풀어 써 놓으면 읽기는 편해도 「여기가 이걸 실제로 하는
곳인가」 하는 의심이 남습니다.

### 그래서 이렇게 씁니다

- **용어를 앞에 두고, 필요하면 뒤에 한 줄 덧붙입니다.**
  「수인한도를 넘어야 위법이 됩니다」처럼 용어를 그대로 쓰되,
  그 문단이 무슨 뜻인지는 앞뒤 문장이 알려주게 합니다.
- **용어를 지우고 풀이만 남기지 않습니다.** 이것이 가장 크게 손해 보는
  방식입니다.
- **검사 이름 · 법 이름 · 사건 이름은 정식 명칭으로 적습니다.**
  근전도검사(EMG), 집합건물법 제9조의2, 낙찰자지위확인, 하도급법 제14조.
- **영문 약어가 실제로 쓰이는 자리는 한글과 함께 적습니다.**
  진료실과 법정에서 약어로 말해야 통하는 경우가 있고,
  두 가지로 모두 검색되기 때문입니다.

### 다만 이 둘은 계속 지킵니다

- **겁주지 않습니다.** 용어를 쓰는 것과 무섭게 쓰는 것은 다릅니다.
- **단정하지 않습니다.** 법정형 · 기간 · 요율 · 판례 번호는
  확인한 것만 적고, 확인한 날짜를 파일 안 주석에 남깁니다.

## 다른 법인처럼 화려하게 나오게 하려면

### 그 화면은 광고입니다

다른 법인 검색 결과에 뜨는 큰 화면(로고 · 사진 여러 장 · SNS 소식)은
**네이버 브랜드검색**이라는 **유료 상품**입니다. 화면 오른쪽 위에 작게
**「광고」**라고 적혀 있습니다.

**홈페이지를 아무리 잘 만들어도 저 자리는 나오지 않습니다.**
검색이 잘 되게 해서 얻는 자리가 아니라 돈을 내고 사는 자리입니다.

값은 이렇게 정해집니다.

```
상품 유형  ×  그 검색어의 최근 30일 조회수  ×  노출 기간(7~90일)
```

클릭당이 아니라 **기간 정액제**입니다. PC 기본형과 모바일 브랜드존은
값 차이가 아주 큽니다. **정확한 금액은 네이버 검색광고에서 견적을
받으셔야 합니다.** 이 문서에 적어두면 곧 틀린 안내가 됩니다.

**우리에게 유리한 점 하나.** 「법무법인유일」은 우리 상호라 검색량이
많지 않습니다. 값이 조회수로 정해지니 **가장 낮은 구간에 들어갈
가능성이 큽니다.**

### ⚠️ 문구는 그대로 따라 하지 마십시오

다른 법인 광고에 보이는 **「압도적 승소율」** 같은 표현은 대한변호사협회
광고규정에서 문제가 될 수 있는 종류입니다. 광고를 하시더라도
**문구는 대표변호사님이 규정을 보고 정하셔야 합니다.**

## 지식iN 탭을 채우는 일에 대하여 (2026-09-25)

**먼저 솔직하게 — 이건 느리고, 효과에 견주어 손이 많이 갑니다.**
플레이스를 먼저 하시고, 이건 그다음에 생각하셔도 늦지 않습니다.

### 법인 계정이 필요한가

**아닐 것으로 봅니다.** 플레이스와는 성격이 다릅니다.

- **플레이스**는 *사업장*을 등록하는 것이라 사업자 정보가 필요합니다.
- **지식iN 전문가답변**은 *자격*을 확인하는 제도입니다. 변호사 자격은
  법인이 아니라 **변호사 개인**에게 붙습니다. 그래서 변호사 한 분
  한 분이 본인 계정으로 신청하고, 프로필에 소속 법인을 적는 구조가
  자연스럽습니다.

★ 다만 **이건 제가 확인해 드리지 못했습니다.** 작업 환경에서 네이버
  지식iN 페이지가 열리지 않습니다. 신청 화면과 제출 서류는
  **네이버 지식iN → 전문가 답변** 쪽에서 직접 확인해 주십시오.
  법인 계정을 못 찾아 막히는 일은 아닐 것이라는 점만 말씀드립니다.

### 탭이 채워지는 원리

지식iN 탭에는 **「법무법인유일」이라는 말이 들어간 질문과 답변**이
모입니다. 우리가 그 탭에 글을 직접 올리는 방법은 없습니다.
답변 활동을 하고, 프로필에 소속이 적혀 있으면 시간이 지나며 쌓입니다.

### ⚠️ 하지 말아야 할 것 — 자문자답

**우리 상호가 들어간 질문을 만들어 올리고 우리가 답하는 방식**은
절대 하지 마십시오. 두 군데에서 걸립니다.

- **네이버** — 지식iN 은 광고성 답변과 아이디 품앗이·대여를 제재합니다.
  걸리면 답변이 통째로 지워지고 활동이 막힙니다. 그때까지 쌓은 것이
  한 번에 사라집니다.
- **대한변호사협회** — 변호사의 광고는 「변호사 광고에 관한 규정」과
  변호사법 제23조의 적용을 받습니다. 변협이 **주요 위반 사례**를
  따로 안내하고 있으니 **활동 전에 대표변호사님이 한 번 보셔야
  합니다.**

  koreanbar.or.kr → 공지 → 「변호사 광고에 관한 규정 주요 위반 사례」

**답변은 답변답게 쓰는 것이 결국 가장 빠릅니다.** 질문에 제대로
답하면 프로필을 타고 들어옵니다. 홍보 문구와 전화번호를 답변에 붙이면
그 답변 하나를 살리려다 계정을 잃습니다.

### 지식iN 보다 블로그가 먼저입니다

같은 품이면 **네이버 블로그**가 낫습니다.

| | 지식iN | 블로그 |
|---|---|---|
| 무엇을 쓸지 | 남이 물어본 것만 | **우리가 정합니다** |
| 상호를 적을 수 있나 | 광고가 되어 위험 | **내 글이라 괜찮습니다** |
| 홈페이지 글 재사용 | 어렵습니다 | **그대로 옮겨 쓸 수 있습니다** |
| 상호 검색 화면 | 아래쪽 | **위쪽** |

홈페이지에 이미 써 둔 글(집합건물 관리비, 의료사고 진단서, 전세사기
공제금 같은 것)을 블로그에 옮겨 쓰고 **홈페이지로 링크**를 걸면,
블로그 탭도 채워지고 홈페이지의 검색 힘도 함께 올라갑니다.
지식iN 답변 한 건보다 이쪽이 몇 배 남습니다.
