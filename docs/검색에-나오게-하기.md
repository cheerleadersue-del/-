# 검색에 나오게 하기

구글 · 네이버 · 다음에서 이 홈페이지가 검색되게 하는 방법입니다.

두 가지로 나뉩니다.

- **저장소에서 해둔 것** — 이미 해두었습니다. 다시 하실 일 없습니다.
- **대표님이 하셔야 하는 것** — 각 회사에 계정으로 들어가 신청하는 일이라
  제가 대신할 수 없습니다. 아래 순서대로 하시면 됩니다.


## 0. 먼저 정하셔야 할 것 — 주소

지금 홈페이지 주소는 이것입니다.

```
https://cheerleadersue-del.github.io/-/
```

**이 주소로 검색 등록을 하시는 것은 권하지 않습니다.**

- 법무법인 주소로 쓰기에 모양이 좋지 않습니다
- 나중에 회사 도메인(예: `yuil-law.co.kr`)을 연결하면 **지금 등록한 것이 전부 헛일**이 됩니다.
  검색엔진이 쌓아둔 것은 주소에 붙지, 내용에 붙지 않습니다.

**그러니 도메인을 먼저 연결하시고, 그다음에 1번부터 하십시오.**
도메인 연결은 반나절이면 됩니다. 말씀해 주시면 순서를 적어 드리겠습니다.

급하시면 지금 주소로 먼저 하셔도 됩니다. 다만 도메인을 연결한 뒤
같은 일을 한 번 더 하셔야 하고, 그동안 쌓인 것은 옮겨오기 어렵습니다.


## 1. 구글

1. <https://search.google.com/search-console> 에 들어가 구글 계정으로 로그인
2. **속성 추가** → **URL 접두어** → 홈페이지 주소를 넣습니다
3. 소유 확인 방법이 여러 개 나오는데 **HTML 태그** 를 고르십시오.
   `<meta name="google-site-verification" content="……">` 같은 줄이 나옵니다.
   **그 줄을 저에게 보내주시면 홈페이지에 넣어 드립니다.**
4. 넣은 것을 올린 뒤 구글 화면에서 **확인** 을 누르십시오
5. 확인되면 왼쪽 **Sitemaps** 에 들어가 `sitemap.xml` 을 넣고 제출

보통 며칠 안에 들어가기 시작하고, 자리를 잡는 데는 몇 주 걸립니다.


## 2. 네이버

1. <https://searchadvisor.naver.com> 에 네이버 계정으로 로그인
2. **웹마스터도구** → **사이트 등록** → 홈페이지 주소를 넣습니다
3. 소유 확인에서 **HTML 태그** 를 고르십시오.
   `<meta name="naver-site-verification" content="……">` 이 나옵니다.
   **그 줄을 저에게 보내주시면 넣어 드립니다.**
4. 확인 뒤 **요청 → 사이트맵 제출** 에 `sitemap.xml` 을 넣으십시오
5. **요청 → 웹페이지 수집** 에 첫 페이지 주소를 한 번 넣어 주시면 더 빠릅니다

네이버는 구글보다 오래 걸립니다. 한 달 정도 보셔야 합니다.


## 3. 다음(카카오)

1. <https://register.search.daum.net/index.daum> 에 들어갑니다
2. **신규 등록** 에서 홈페이지 주소와 연락처를 넣고 신청하십시오
3. 계정 로그인이나 파일 업로드 없이 신청만으로 됩니다

사람이 검토하므로 며칠에서 몇 주 걸립니다.


## 4. 네이버 플레이스 — 가장 중요합니다

**"법무법인 유일" 로 검색하는 분은 대부분 플레이스를 먼저 봅니다.**
웹사이트 검색 순위보다 이쪽이 훨씬 빨리, 훨씬 크게 나옵니다.

1. <https://smartplace.naver.com> 에 로그인
   (이미 등록된 업체라면 **내 업체** 에 나옵니다)
2. **업체정보 수정** → **홈페이지** 칸에 새 주소를 넣으십시오
3. 함께 확인하실 것
   - 대표전화 **02-563-0625** 가 맞는지
   - 주소 · 영업시간(평일 09:00–18:00) · 주차 안내
   - 대표 사진을 새 홈페이지의 것과 맞추기

플레이스가 등록되어 있지 않다면 새로 등록하셔야 합니다.
사업자등록증과 간판 사진이 필요합니다.


## 5. 예전 홈페이지를 어떻게 할지 정하십시오

**이것을 정하지 않으면 두 사이트가 서로를 깎아먹습니다.**

같은 법인 이름으로 된 사이트가 둘이면 검색엔진은 어느 쪽이 진짜인지
판단하지 못합니다. 그래서 둘 다 순위가 낮아집니다.
새 홈페이지만 올린다고 예전 것이 밀려나지 않습니다.

고르실 수 있는 길은 셋입니다.

| | 무엇을 하는가 | 결과 |
|---|---|---|
| **A. 넘기기** (권합니다) | 예전 주소로 들어오면 새 홈페이지로 자동으로 넘어가게 합니다 | 예전 사이트가 쌓아둔 것이 새 홈페이지로 넘어옵니다. 가장 좋습니다 |
| **B. 닫기** | 예전 사이트를 내립니다 | 깨끗하지만, 쌓아둔 것은 버려집니다 |
| **C. 그대로 두기** | 아무것도 안 합니다 | 둘이 계속 경쟁합니다. 권하지 않습니다 |

A를 하시려면 예전 홈페이지를 만든 곳이나 관리하는 곳에
**"301 리다이렉트로 새 주소로 넘겨 달라"** 고 하시면 됩니다.
그쪽에서 무슨 말인지 압니다.

예전 홈페이지 주소를 알려주시면 지금 무엇이 걸려 있는지 확인해 드리겠습니다.
(제 작업 환경에서 바깥 사이트 접속이 막혀 있어 직접 열어보지는 못하지만,
 어떻게 넘기면 되는지는 정리해 드릴 수 있습니다.)


## 6. 그밖에 도움이 되는 것

검색은 "누가 이 사이트를 가리키는가" 를 크게 봅니다.
법인 이름으로 이미 나오는 곳마다 홈페이지 주소를 넣어 두십시오.

- 대한변호사협회 · 서울지방변호사회 회원 정보
- 네이버 지도 · 카카오맵 업체 정보
- 블로그 · 인스타그램 등 운영 중인 계정의 소개란
- 명함 · 사무실 안내문 · 메일 서명


## 저장소에서 해둔 것 (다시 하실 일 없음)

| 무엇 | 하는 일 |
|---|---|
| `sitemap.xml` | 33개 쪽의 목록. 검색엔진이 한 번에 읽습니다 |
| `robots.txt` | 모든 쪽을 찾아가도 된다는 표시와 사이트맵 주소 |
| `canonical` (35장) | 이 쪽의 진짜 주소가 어디인지. 주소가 여러 개로 갈릴 때 하나로 모아줍니다 |
| `og:url` (32장) | 카톡 · SNS 미리보기가 가리킬 주소 |
| 구조화 데이터 | 법인 이름 · 주소 · 전화 · 영업시간 · 다루는 분야를 기계가 읽는 형식으로 |

상담 완료 쪽(`thanks.html`)과 없는 쪽(`404.html`)은 검색에 안 잡히게 해두었고
사이트맵에서도 뺐습니다.


## 주소를 바꾸실 때

도메인을 연결하시면 아래 한 줄로 모든 파일의 주소가 바뀝니다.
저에게 말씀하시면 해 드리겠습니다.

```sh
grep -rl "cheerleadersue-del.github.io/-" --include=*.html --include=*.xml --include=*.txt . \
  | xargs sed -i 's|https://cheerleadersue-del.github.io/-|https://새주소|g'
```
