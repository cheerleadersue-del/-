# 사진 넣는 곳

여기에 **원본 그대로** 올리시면 됩니다. 크기를 줄이거나 자르지 않으셔도 됩니다.

## 올리는 법

1. 깃허브에서 이 `_incoming` 폴더로 들어갑니다
2. 오른쪽 위 **Add file → Upload files**
3. 사진을 끌어다 놓고 아래 **Commit changes** 를 누릅니다

## 파일 이름

**어떤 이름이든 상관없습니다.** 다만 어디에 쓸 사진인지 알 수 있게
적어주시면 좋습니다. 예를 들면 이렇게요.

```
띠-야경.jpg
배너-가사.png
머리-이혼.jpg
```

이름을 정하기 어려우시면 그냥 올리시고, 채팅으로 "왼쪽부터 순서대로
이혼 · 상속 · 양육권" 처럼 알려주셔도 됩니다.

## 그다음

제가 자리에 맞게 자르고, 크기를 맞추고, 용량을 줄여서
`assets` 폴더에 올바른 이름으로 넣습니다. 그리고 이 폴더는 비웁니다.

이 폴더의 파일은 **홈페이지에 올라가지 않습니다.** 손님에게 보이지 않습니다.
