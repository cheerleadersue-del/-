# 아직 켜지 않은 쪽

여기 있는 파일은 **홈페이지에 나가지 않습니다.**
깃허브 페이지스와 넷리파이 양쪽에서 빼 두었습니다.

만들어는 두었지만 아직 공개하지 않기로 한 것을 여기에 둡니다.


## 지금 들어 있는 것

**없습니다.**

건설(`civil-construction.html` · `civil-construction.js`)이 여기 있었는데
2026-09-23 에 홈페이지로 옮겼습니다. 민사 센터 배너의 **02번** 자리에
들어갔고, 첫 화면 민사 칸의 알약과 사이트맵에도 넣었습니다.


## 새로 넣으실 때

초안을 여기 두시면 배포에서 빠집니다. 켜실 때는 네 군데를 손보면 됩니다.

1. **파일을 제자리로** — `git mv _draft/○○.html .`
2. **센터 배너에 넣기** — 해당 센터의 `○○-list.js` 에 항목을 더하고
   뒤 항목의 `no` 를 한 칸씩 밉니다
3. **첫 페이지 칸의 알약에 넣기** — `main.js` 의 `practices`
4. **사이트맵에 넣기** — `sitemap.xml`. 이 줄이 없으면 검색에 안 잡힙니다


## 이 폴더를 막아둔 곳

| 어디 | 무엇 |
|---|---|
| `.github/workflows/pages.yml` | `--exclude='_draft'` — 깃허브 페이지스로 안 나갑니다 |
| `netlify.toml` | `/_draft/*` → 404 — 넷리파이에서도 안 열립니다 |

넷리파이는 저장소 파일을 그대로 올리는 방식이라
빠뜨리면 주소를 아는 사람이 열어볼 수 있습니다. 그래서 두 곳을 다 막았습니다.
