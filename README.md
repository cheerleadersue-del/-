정적 웹사이트(HTML · CSS · JavaScript). 빌드 도구 없이 파일 그대로 배포합니다.

#### 사진 띠에 사진 넣기

지금은 어두운 바탕에 문장만 있습니다.
`assets/` 에 아래 이름으로 올리면 **그 자리에 사진이 깔립니다.**

```
assets/drug-1.webp   또는 .jpg / .jpeg / .png
assets/drug-2.webp
```

가로로 넓게 잘리므로 **가로 1600px 이상**을 권합니다.
사진 위에는 자동으로 어두운 막이 씌워져 글자가 읽힙니다.

기존 `center-criminal.webp` 는 416×358 로 작아 띠에 쓰면 뭉개집니다.
그래서 쓰지 않았습니다.

#### 새 분야 페이지 만들기

`criminal-drug.html` 과 `criminal-drug.js` 를 복사해 이름을 바꾸고 내용만 교체합니다.
`criminal-drug.js` 의 `window.PAGE_DATA` 에 그 페이지의 질문과 담당 변호사를 적고,
`main.js` 의 형사 `tags` 에서 해당 항목의 `href` 를 채우면 링크가 살아납니다.

## 첫 화면 사진 바꾸기

**파일만 올리면 됩니다. 코드는 손대지 않아도 됩니다.**

`assets/` 에 아래 이름 중 하나로 올리세요.

```
assets/hero.webp      ← 이 순서로 찾습니다
assets/hero.jpg
assets/hero.png
```

셋 중 하나가 있으면 그것을 쓰고, 없으면 지금 걸린 법조타워 사진
(`hero-building.webp`)이 그대로 남습니다.

가로로 넓게 잘리므로 **가로 1600px 이상**을 권합니다.
원래대로 되돌리려면 올린 `hero.*` 파일을 지우면 됩니다.

### 동영상으로 바꾸려면

**사진과 똑같습니다. 파일만 올리시면 됩니다.**

```
assets/hero.mp4       ← 이것을 먼저 찾습니다
assets/hero.webm      ← mp4 가 없으면 이것
```

올리는 순간 첫 화면이 동영상으로 바뀝니다. HTML 은 고치지 않습니다.
지우면 다시 사진으로 돌아갑니다.

동작 방식은 이렇습니다.

- 동영상은 **사진 위에 겹쳐** 두고, 재생이 실제로 시작된 뒤에
  0.9초에 걸쳐 서서히 나타납니다. 느린 통신에서 검은 네모가
  스치는 일이 없습니다.
- 파일이 없거나 · 브라우저가 자동재생을 막거나 · 첫 프레임이
  끝내 안 나오면 → **조용히 사진 그대로** 남습니다.
- **소리는 항상 꺼져 있습니다.** (`muted` 없이는 어느 브라우저도
  자동재생을 허용하지 않습니다.)
- 기기에서 **"동작 줄이기"** 를 켜 둔 분, **데이터 절약 모드**를
  켜 둔 분에게는 동영상을 아예 내려받지 않습니다.

준비하실 때 유의할 점.

- **용량 5MB 이하.** 첫 화면에서 바로 내려받는 파일입니다.
  10초 내외로 잘라 반복 재생시키는 편이 낫습니다.
- **소리는 지워서 올리세요.** 어차피 재생되지 않는데 용량만 차지합니다.
- **가로 1920px, mp4(H.264)** 면 모든 기기에서 재생됩니다.

### 지금 들어가 있는 영상

`assets/hero.mp4` — 1920 × 800, 5초, 30fps, 소리 없음, 1.7MB.
H.264 High Profile Level 4.0 이라 모든 브라우저에서 재생됩니다.

**휴대폰에서는 좌우가 많이 잘립니다.** 영상이 가로로 매우 긴 비율
(2.4 : 1)이라, 세로로 긴 휴대폰 화면을 채우면 **가운데 21% 만** 보입니다.
태블릿은 45%, PC 는 63% 가 보입니다.

휴대폰에서 보시고 어색하면 `main.js` 에서 이 한 줄만 고치세요.

```js
const HERO_VIDEO_MIN_WIDTH = 0;     →     const HERO_VIDEO_MIN_WIDTH = 820;
```

이러면 휴대폰은 사진, 태블릿·PC 는 영상이 나옵니다.

### 영상을 다른 것으로 바꿀 때

`assets/*` 는 브라우저가 **1년간 캐시**하도록 설정돼 있습니다
(그래야 재방문이 빠릅니다). 그래서 `hero.mp4` 를 같은 이름으로
덮어쓰면 **한 번 방문했던 분에게는 옛 영상이 계속 보일 수 있습니다.**

영상을 교체하실 때는 알려주세요. 파일 이름과 코드를 함께 바꾸면
모두에게 새 영상이 바로 보입니다.

### 사진 저작권

`assets/hero-building.webp` 는 **직접 촬영하신 사무실 건물 사진**이라 문제가 없습니다.

인터넷에서 받은 사진을 쓰실 때는 상업적 이용이 허용되는지 반드시 확인하세요.
법인 홈페이지는 상업적 이용에 해당합니다. 무료로 쓸 수 있는 곳은
Unsplash, Pexels 등이 있습니다.

## ⚠️ 공개 전 반드시 확인할 것

### 1. 의뢰인 질문 7문항의 법률 내용 — 가장 중요

`main.js` 상단 `questions` 배열에 구속영장실질심사, 불송치 이의신청,
성범죄, 의료사고, 대여금 등 **법률 절차 설명이 들어 있습니다.**

이 문구는 일반적인 절차를 설명한 초안입니다.
**반드시 변호사가 직접 검토하고 수정하신 뒤 공개하세요.**
법 개정이나 실무 변화가 반영되지 않았을 수 있습니다.

특히 다음 항목은 재확인이 필요합니다.

- 불송치 이의신청 — **고발인의 이의신청권이 제외**된다고 썼습니다. 현행 조문 확인 필요
- 영장실질심사가 "청구 다음 날 열리는 것이 보통"이라는 서술
- 의료사고·대여금의 소멸시효 — 기간을 명시하지 않았으나 표현 검토 필요
- "착수 전에 서면으로 확인되지 않은 비용은 청구하지 않습니다" —
  **유일의 실제 수임 방침과 맞는지** 확인 필요

### 2. 사진 파일 이름 — 확장자를 두 번 붙이지 마세요

양진희 변호사 사진이 `lawyer-06.png.webp` 로 올라와 있었습니다.
확장자가 두 번 붙으면 코드가 찾지 못합니다. `lawyer-06.webp` 로 고쳤습니다.

파일을 올리실 때는 **점 뒤에 확장자가 하나만** 오게 해주세요.

```
lawyer-06.webp     ✓
lawyer-06.png.webp ✗
```

윈도우에서 "파일 확장자 숨기기" 가 켜져 있으면 이런 일이 생깁니다.
`lawyer-06` 으로 이름을 바꾸시면 실제 이름은 `lawyer-06.webp` 가 됩니다.

### 3. 변호사 사진과 성명 — 확정됨

기존 홈페이지의 변호사 순서와 경력(기수 · 사법시험 회차)을 대조해 확정했습니다.

| 순서 | 성명 | 사진 | 대조 근거 |
|---|---|---|---|
| 1 | 정호길 대표변호사 | `lawyer-01-portrait.webp` | 25년차 · 제40회 · 연수원 30기 |
| 2 | 양진희 변호사 | `lawyer-06.webp` | 변시 11회 · 고려대 · 前 법무법인 송우 |
| 3 | 심상한 변호사 | `lawyer-02.webp` | 제49회 · 연수원 39기 · 노동위 공익위원 |
| 4 | 정주현 변호사 | `lawyer-03.webp` | 연수원 30기 · 중앙지법 조정위원 · 저서 |
| 5 | 김제도 변호사 | `lawyer-04.webp` | 연수원 47기 · 서울서부지검 검사 직무대리 |

### 4. 로고

원본 벡터 파일(`.ai` · `.svg`)이 있으시면 교체하는 편이 정확합니다.

### 5. 지도 — 실제 화면에서 확인해 주세요

API 키 없이 동작하는 Google Maps 임베드를 넣었습니다.
**제 작업 환경은 외부 접속이 막혀 있어 지도가 실제로 뜨는지 확인하지 못했습니다.**
배포된 사이트에서 직접 확인해 주세요.

지도가 안 뜨면 `index.html` 의 `.map` 안 `<iframe>` 을 지우고
카카오/네이버 바로가기 링크만 남기셔도 됩니다. 그 링크는 항상 동작합니다.

국내 이용자를 위해 바로가기 버튼을 함께 두었습니다.
**네이버지도는 법인이 알려준 실제 장소 링크(`https://naver.me/GALRcuul`)를 씁니다.**
장소 정보가 바뀌면 `index.html` 의 `.map-link-main` href 만 교체하시면 됩니다.

또한 `.map-note` 에 **가까운 지하철역과 주차 안내가 비어 있습니다.**
제가 추측으로 쓰지 않았으니 실제 정보로 채워주세요.

시트는 장부로 쓰고 알림은 위 방법으로 따로 받으셔야 합니다.

`netlify/functions/submission-created.js` — 파일 이름 때문에 Netlify 가

## 내용 수정하기

`main.js` 상단 세 배열에서 관리합니다.

```js
const questions = [
  { tag: "형사", q: "질문", a: ["문단1", "문단2"] },
];

const practices = [
  { name: "형사", en: "CRIMINAL", image: "assets/center-criminal.webp",
    desc: "...", tags: ["구속영장", "압수수색"] },
];

const attorneys = [
  { name: "정호길", role: "대표변호사", field: "형사 · 수사 및 재판 대응",
    image: "assets/lawyer-01.webp", career: ["25년 경력 형사전문"] },
];
```

- 질문은 개수 제한이 없습니다. 번호는 자동으로 매겨집니다.
- **변호사 경력은 앞 3줄만 보이고 나머지는 "경력 더 보기" 로 접힙니다.**
  `career` 배열에 몇 줄을 더 넣어도 카드 높이는 그대로입니다.
  보이는 줄 수는 `main.js` 의 `OPEN_COUNT` 로 바꿉니다.
- 업무분야 이름은 **두 글자**로 맞추세요. 길면 닫힌 칸에서 잘립니다.
- 업무분야의 `credit` 은 담당 변호사를 알리는 줄입니다. **비워두면 그 줄이 아예 안 나옵니다.**
  담당이 정해지지 않은 분야는 `credit` 을 빼두세요. (현재 공증이 그렇습니다)
- 형사의 `tags` 는 세부 분야 목록입니다. `{ name, href }` 형태로 적으며
  **`href` 를 채우면 링크(화살표 붙음), 비우면 그냥 글자**로 나옵니다.
  다른 분야의 `tags` 는 예전처럼 문자열만 적어도 됩니다.
- 히어로 문구와 인사말, 원칙 3항목은 `index.html` 에 직접 적혀 있습니다.

## 이미지 다시 만들기

```bash
pip install Pillow
python3 - <<'EOF'
from PIL import Image
import os
SRC = "원본폴더"
for f in os.listdir(SRC):
    if not f.endswith(".png"): continue
    im = Image.open(os.path.join(SRC, f)).convert("RGB")
    if im.width > 1600:
        im = im.resize((1600, round(im.height * 1600 / im.width)), Image.LANCZOS)
    im.save("assets/" + f[:-4] + ".webp", "WEBP", quality=82, method=6)
EOF
```

## 참고 — 반복해서 걸렸던 것들

- 한글 명조 제목은 `line-height` 를 **1.3 아래로 내리지 않습니다.** 획이 겹칩니다.
- `<br>` 을 모바일에서 숨길 때는 **`<br>` 앞에 공백을 둡니다.** 그러지 않으면
  단어가 붙어 "기록 속 놓친 단서와진술의 모순" 처럼 보입니다.
- 그리드에서 **일부 자식만 위치를 지정하면 나머지가 엉뚱한 칸으로 밀립니다.**
  `.q-head` 에서 이 문제로 가로 넘침이 났습니다. 셋 다 `grid-area` 로 못박습니다.
- `max-width` 에 `ch` 단위를 쓰면 한글에서 너무 좁아집니다. `px` 을 씁니다.
- 인물 사진은 **세로 비율**입니다. 좁은 화면에서 가로로 눕히면 눈높이 한 줄만 남습니다.
- `img` 의 `height` 속성은 CSS `aspect-ratio` 를 **눌러버립니다.** 둘을 같이 쓰려면
  CSS 에 `height: auto` 를 반드시 넣습니다. 이걸 빠뜨려 모바일에서 변호사 사진이
  124x998 로 늘어났습니다.
- `assets/lawyer-01.webp` 는 배경을 지운 **컷아웃**이라 `object-fit` 은 `contain` 입니다.
- **Playwright 의 `fullPage` · 요소 촬영은 레이아웃을 왜곡합니다.** 화면 밖까지 담으려고
  뷰포트를 늘리기 때문에, flex 비율이 실제와 다르게 찍힙니다. 폭이 이상해 보이면
  사진을 믿지 말고 `getBoundingClientRect()` 로 재보세요.
  (업무분야 패널이 잘려 보였지만 실제로는 441 / 170px 로 정상이었습니다.)
- 지연 로딩(`loading="lazy"`) 이미지는 화면에 들어온 적이 없으면 촬영에서 빈칸으로 나옵니다.
  깨진 것이 아니니 스크롤을 먼저 태우고 확인하세요.
- 히어로가 어두운 사진이므로 **헤더 글자는 밝게 시작**해야 합니다.
  스크롤해 히어로를 지나면 `.is-stuck` 이 붙어 어두운 글자로 바뀝니다.
